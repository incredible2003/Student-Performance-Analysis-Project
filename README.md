# Student-Performance-Analysis-Project
Analyzed student performance dataset using Pandas and Matplotlib. Created visualizations to compare subject-wise marks, attendance, and overall student performance.
## Student Performance Analysis Project
Performed student data analysis using Python and visualization libraries.

### Key Tasks
- Student marks analysis
- Attendance tracking
- Visualization using bar charts, histograms, and pie charts
- Performance comparison

### Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
